# SQL Analysis

This folder contains the PostgreSQL scripts used in the E-commerce Sales & Customer Analytics project.

## Planned SQL scripts

| Script | Purpose |
|---|---|
| 01_data_exploration.sql | Explore database tables and schemas |
| 02_data_quality_checks.sql | Identify missing values, duplicates and inconsistencies |
| 03_sales_analysis.sql | Analyze sales trends and order performance |
| 04_customer_analysis.sql | Analyze customer behavior, repeat purchases and RFM segments |
| 05_cohort_analysis.sql | Calculate customer cohort retention |
| 06_delivery_analysis.sql | Analyze delivery performance and customer reviews |
| 07_category_analysis.sql | Analyze product category performance |
| 08_analytical_views.sql | Create SQL views for Power BI |

All scripts will be organized by analytical task and executed using PostgreSQL.
